# Hands-on TensorFlow

This repository contains **practical TensorFlow labs and exercises** created during my training, mainly inspired by Coursera courses.  
The goal is hands-on learning through experimentation, reimplementation, and extension of concepts in deep learning using TensorFlow.

## Objectives
- Practice core TensorFlow and Keras APIs
- Implement neural networks from scratch and with high-level abstractions
- Experiment with CNNs, DNNs, and basic ML workflows
- Build a reusable personal reference for TensorFlow projects
